paper-lantern started as a weekend script to rebuild one blog. It turned into a tool because three other writers wanted the same thing: write Markdown, get fast pages, keep the output readable.

## What it will never do

- Ship JavaScript to readers by default.
- Need a database.
- Hide the output folder behind a build cache you cannot inspect.

The longer story is in the draft post [why paper-lantern](../../../../notes/drafts/why-paper-lantern.md).
