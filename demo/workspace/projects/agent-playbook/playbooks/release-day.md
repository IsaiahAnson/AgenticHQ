# Release day

1. Freeze `main` in the morning; only release fixes merge.
2. `/release-notes` drafts the notes from merged PRs. A person edits them.
3. `/ship` runs the checklist: version bump, changelog, tag, build, publish.
4. Post the announcement draft; a person sends it.
5. Watch the issue tracker for 24 hours. Theo is on point for CI.

Cadence and timing: [memory/release-cadence.md](../../../memory/release-cadence.md).
