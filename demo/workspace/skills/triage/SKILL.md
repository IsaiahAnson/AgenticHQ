# /triage

## Steps
1. Pull unread mail and new issues since the last run.
2. Group by project first, then by sender ([lesson](../../memory/lessons/inbox.md)).
3. Label each: **act** (needs me today), **reply** (a draft is enough), **read** (newsletters, digests), **archive**.
4. For **reply**, write a short draft in my voice. Never send.
5. Publish the summary as a ring page: counts, the act list and links to drafts.

## Rules
- Drafts only. No sends, no auto-replies, no forwarding.
- Collaborators get a draft, never a template ([collaborators](../../memory/collaborators.md)).

## Gotchas
- 2026-10-24: twelve notifications from one repository buried a real message. Collapse notifications per repository.
