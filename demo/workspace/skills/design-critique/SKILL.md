# /design-critique

## Steps
1. Take screenshots at phone, tablet and desktop widths, light and dark.
2. Check hierarchy: what does the eye land on first?
3. Check contrast against WCAG AA for body and muted text.
4. Check every state: empty, loading, error, offline, long content.
5. Read the copy out loud. Cut words.
6. Return three changes that matter most, then the rest.

## Gotchas
- 2026-10-14: muted text on the dusk theme failed AA. Check muted text first on dark themes.
