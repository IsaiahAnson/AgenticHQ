# /standup

## Steps
1. Read yesterday's commits and merged PRs across projects.
2. Read [notes/now.md](../../notes/now.md) and yesterday's journal entry.
3. Write three short sections: **Done**, **Today**, **Blocked**.
4. Save as a draft note. Do not post it anywhere.

## Gotchas
- 2026-10-20: weekend commits showed up as "yesterday" on Monday. On Mondays, cover Friday to Sunday.
