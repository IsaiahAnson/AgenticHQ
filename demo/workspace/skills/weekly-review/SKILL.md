# /weekly-review

## Steps
1. Collect merged PRs, closed issues and releases per project.
2. Read routine runs: which ran, which failed, which were skipped.
3. List new lessons and skill gotchas added this week.
4. Note which agent lanes did the work.
5. Write the ring page "The week in HQ": highlights, numbers, what slipped, three priorities for next week.

## Gotchas
- 2026-10-28: ring pages are static. Bake the numbers into the page; do not fetch them.
