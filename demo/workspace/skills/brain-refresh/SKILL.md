# /brain-refresh

## Steps
1. Run the scan from the HQ folder.
2. Run the brain refresh to rebuild the snapshot, skills list and orb.
3. Open the map and check the department counts look right.
4. If a folder landed in the wrong department, fix the path rule, not the folder.

## Gotchas
- 2026-10-18: after moving notes, the map kept old paths until the refresh ran. The routine runs every three hours; run it by hand after a reorganization ([lesson](../../memory/lessons/hq-operations.md)).
