# Workspace map

- `projects/<name>/`: code, docs and tests for each project ([index](../projects/README.md))
- `notes/meetings/`: one file per meeting, named `YYYY-MM-DD-topic.md`
- `notes/ideas/`: one idea per file
- `notes/journal/`: daily notes, private, never shared with web lanes
- `notes/drafts/`: posts and talks in progress
- `memory/`: this folder; facts and lessons
- `skills/<name>/SKILL.md`: one skill per folder
- `ops/`: runbooks, backups, CI notes, companions

The router for agents is [AGENTS.md](../AGENTS.md).
