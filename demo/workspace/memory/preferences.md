# Preferences

- Drafts, never sends. Mail, chat, posts and release announcements wait for me.
- Times in anything I read: 12-hour ("2:30 PM"). ISO in file names and JSON.
- Reports: what changed, what was run, what is left. Short.
- Ask before deleting anything outside a scratch folder.
- Finished HTML pages go on the HQ ring with a sidecar.
