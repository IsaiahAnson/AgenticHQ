# Release cadence

- Friday 3:00 PM: `/release-notes` drafts notes for anything merged that week.
- Tuesday: ship. Never ship on a Friday.
- Minor versions every four to six weeks; patch releases when a fix is ready.
- Theo watches CI for 24 hours after each release.

Release day steps: [release-day playbook](../projects/agent-playbook/playbooks/release-day.md). Lessons: [releases](lessons/releases.md).
