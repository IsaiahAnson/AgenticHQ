# Lessons: releases

- **Draft release notes from merged PRs, then a person edits them.** Generated notes listed internal refactors as features. 2026-10-02 [ref: release-notes]
- **Never ship on a Friday.** 0.8.1 went out on a Friday evening and the fix waited until Monday. 2026-09-19 [ref: release-cadence]
- **Tag only after CI is green on the release commit.** 2026-10-16 [ref: ship]
