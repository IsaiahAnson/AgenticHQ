# Local companions

Small tools that run next to HQ. All local, all optional.

| Companion | What it does here |
|---|---|
| promptfoo | Evals for prompts used by skills and the radar sweep |
| QMD | Local search over notes and memory |
| Basic Memory | Notes that agents can read and write between sessions |
| CASS | Search across past agent sessions |
| ntfy | Push alerts: backups, sensor boxes, failed routines |
| changedetection | Watches docs and changelogs of key dependencies |
| Karakeep | Bookmarks and the reading list inbox |

`fk doctor` checks that ntfy and Karakeep answer ([commands](../../projects/fieldkit/docs/commands.md)).
