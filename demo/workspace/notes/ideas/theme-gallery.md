# Idea: paper-lantern theme gallery

A small site built with paper-lantern itself: one sample post rendered in every theme, side by side, with a link to each theme folder.

- Generate screenshots at build time with Playwright.
- Community themes go in through a pull request with a `theme.json`.
- Parked until after 0.9 ([release planning](../meetings/2026-10-28-release-planning-0-9.md)).

Theme format: [themes.md](../../projects/paper-lantern/docs/themes.md).
