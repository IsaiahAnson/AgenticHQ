# Draft: why paper-lantern

Every few years the blog tool I use grows a plugin system, a build server and a theme marketplace. I wanted the opposite: a folder of Markdown, a folder of HTML, and a tool in between I can read in an afternoon.

## Points to make
- The output folder is the product. You can open it, diff it, host it anywhere.
- Themes are five files and one stylesheet. See [the themes doc](../../projects/paper-lantern/docs/themes.md).
- Speed comes from skipping work, not from clever code: unchanged posts are not rebuilt.
