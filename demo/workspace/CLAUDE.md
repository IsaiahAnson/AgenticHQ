# CLAUDE.md

Read [AGENTS.md](AGENTS.md) first. It is the router for every agent in this workspace; this file only adds what is specific to Claude Code.

- **Lessons first.** Before a multi-step plan, skim [memory/MEMORY.md](memory/MEMORY.md) and the lesson file for the area you are about to touch.
- **Skills** live in `skills/<name>/SKILL.md`. When one hits friction, fix it and add a dated line under `## Gotchas`.
- **Hand off long test runs** to Codex in its own worktree ([agent-playbook/docs/parallel-workers.md](projects/agent-playbook/docs/parallel-workers.md)).
- **Never send.** Mail and chat replies are drafts; releases wait for the `/ship` checklist.
- **Ring pages.** A finished report or dashboard goes to the HQ ring with a sidecar (title, icon, kind, created, note, svg).
- **Times.** Write clock times for people in 12-hour form ("9:40 AM").
- After moving or renaming folders, run `/brain-refresh` so the Second Brain map matches.
