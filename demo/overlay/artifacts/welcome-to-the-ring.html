Welcome to the ring

Every page a routine or a session writes for you lands here, newest first. Open one to read it; nothing on the ring runs code or calls out.

01What lands here

02Anatomy of a ring page

  morning-brief.json   sidecar

{
  "title": "Morning brief",
  "icon": "mail",
  "kind": "report",
  "created": "2026-10-27T11:31:00.000Z",
  "note": "One line for the card",
  "svg": "<circle cx=\"24\" cy=\"24\" r=\"8\"/>"
}
title
The card name. Falls back to the page's own title.
icon
One of dash, deck, report, mail, video, chart, visual, bolt, doc, mic.
kind
A short word: report, draft, digest, review, run, guide.
created
ISO time. People see it as 12-hour time, like 7:31 AM.
note
One line under the title.
svg
One to four plain shapes on a 48 by 48 grid. HQ colors them.

03House rules

  • Static only. No scripts, no fetching, no storage. Bake the numbers into the page when it is written.
  • Dark, in HQ colors. Inline styles and system fonts, so a page looks right offline and in a screenshot.
  • 12-hour times for people. ISO times stay in the sidecar and in file names.
  • No secrets. A page that would hold a key, a token or a private address stays off the ring.
  • Same name, same stack. Pages named standup-2026-11-02.html, standup-2026-11-03.html and so on stack into one card.
