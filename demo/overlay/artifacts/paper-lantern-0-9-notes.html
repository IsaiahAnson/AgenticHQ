paper-lantern 0.9.0

A darker theme, a second feed, and builds that skip what did not change

paper-lantern 0.9 adds dusk, a dark reading theme, writes JSON Feed next to Atom, and rebuilds a 400-post site in under a second.

New

  • dusk theme. A dark reading theme with a quiet sidebar, tuned for long posts. Switch with theme = "dusk" in lantern.toml.
  • JSON Feed. Every site now publishes feed.json beside atom.xml. Both are on by default; turn either off in config.
  • Tags on new posts. lantern new post asks for tags and suggests the ones you use most.

Improved

  • Incremental builds. Pages whose source, theme and data did not change are skipped. Pass --no-cache to force a full build, for example on a network drive.
  • Feed dates keep their time zone offset.

Fixed

  • Footnotes inside lists rendered twice.
  • Tag pages lost their sort order on Windows (already in 0.8.2; drop?).

Upgrading

npm install paper-lantern@latest
lantern build --no-cache   # first build after upgrading

Thanks to Priya for the dusk theme review, Jordan for the docs, and Theo for the release builds.
